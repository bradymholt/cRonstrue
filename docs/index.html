See the README for browser, CDN, CLI and i18n usage.

  • Zero dependencies, with TypeScript type definitions
  • Supports all special characters, including * / , - ? L W #
  • Supports 5, 6 (with seconds or year) and 7 part expressions
  • Supports Quartz Job Scheduler expressions and nicknames like @daily
  • 40+ languages
